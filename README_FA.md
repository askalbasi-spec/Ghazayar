# غذایار برای اندروید

این پروژه، نسخه وب غذایار را در یک برنامه Android مبتنی بر WebView اجرا می‌کند و تغییرات زیر را دارد:
- دکمه بازگشت در رابط کاربری و مدیریت دکمه Back اندروید
- گزارش‌های چاپی با قالب A4 و امکان ذخیره به PDF از پنجره چاپ اندروید
- دکمه اشتراک‌گذاری گزارش‌ها با برگه اشتراک‌گذاری سیستم
- صفحه سیاست حریم خصوصی و پشتیبانی با ایمیل esmlotfi@gmail.com
- حفظ امکانات قبلی برنامه و داده‌های محلی

## ساخت APK
با بارگذاری محتویات پروژه در ریشه مخزن GitHub، workflow موجود در `.github/workflows/build-android.yml` می‌تواند APK آزمایشی بسازد.

توجه: پروژه در این محیط روی گوشی واقعی آزمایش نشده است. APK ساخته‌شده باید قبل از انتشار نصب و آزمایش شود و برای عرضه عمومی نسخه release باید امضا شود.
