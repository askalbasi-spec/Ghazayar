# پروژه اندروید غذایار

محتویات `app/src/main/assets/www` نسخه وب غذایار است که داخل WebView اجرا می‌شود. تمام فایل‌ها و پوشه‌های این ZIP را در ریشه مخزن GitHub بارگذاری کنید. پس از Commit، workflow با نام `Build Ghazayar Android APK` اجرا می‌شود و APK آزمایشی در Artifacts قرار می‌گیرد.

**مهم:** این خروجی debug و برای آزمایش است؛ انتشار در کافه‌بازار به نسخه release امضاشده نیاز دارد. داده‌ها فعلاً محلی هستند و همگام‌سازی ابری چنددستگاهی تنظیم نشده است.
