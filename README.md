# غذایار — نسخه اندروید

این مخزن برای آماده‌سازی نسخه اندرویدی غذایار و ساخت خودکار APK با GitHub Actions است.

## ساخت خودکار
پس از قرار گرفتن فایل‌های پروژه Android Studio در ریشه مخزن، به زبانه **Actions** بروید و اجرای **Build Ghazayar Android APK** را بررسی کنید. خروجی موفق در بخش Artifacts با نام `Ghazayar-Android-APK` قرار می‌گیرد.

## مشخصات مورد انتظار
- Android application id: `ir.ghazayar.app`
- Java 17
- Android Gradle Plugin 8.7.3
- SDK 35
- حداقل Android 6.0 (API 23)

## نکته انتشار
APK آزمایشی ساخته‌شده توسط Actions برای تست است. قبل از انتشار در کافه‌بازار، شناسه بسته را با شناسه نهایی برنامه تطبیق دهید، روی گوشی واقعی تست کنید و نسخه انتشار را با کلید امضای خودتان امضا کنید. کلید امضا و رمز آن را هرگز در مخزن GitHub قرار ندهید.
